# GhostScript AI Command Assistant

This example demonstrates a simulated 'GhostScript AI' terminal assistant. It takes natural language prompts from the user, interprets them using a simple rule-based AI, and suggests appropriate GhostScript commands for PDF manipulation. The script then offers to 'execute' these commands by printing them, simulating a smart terminal experience without requiring GhostScript to be actually installed.

## Language

`python`

## How to Run

1. Save the code as `main.py`.
2. Run from your terminal: `python main.py`
3. Interact with the GhostAI prompt (e.g., 'compress my pdf', 'convert pdf to jpeg high quality').
